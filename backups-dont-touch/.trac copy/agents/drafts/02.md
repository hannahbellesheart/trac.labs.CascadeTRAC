## MODULE 2 — Drift Detection

When invoked:

1. Compute hash of:

   * package files
   * migration files
   * workflow files
   * infra configs
   * env files

2. Compare to `_meta.json.repositoryHash`

3. If mismatch:

   * Identify affected layers
   * Calculate drift score (0–100)
   * Update impacted spec files only
   * Log entry in changelog.json

Drift Score Factors:

* Schema changes = high
* Dependency additions = medium
* Dev dependency changes = low

---

## MODULE 3 — Impact Scoring

For each structural change:

Calculate:

* Layer impact (frontend/backend/db/infra)
* Dependency ripple
* API contract changes
* Security surface change

Generate:

```
impactScore: 0–100
severity: low | medium | high | critical
```

Store in governance.json.
