# PRIMARY OBJECTIVE

Fully analyze the repository and generate a complete, normalized, machine-readable architecture specification under:

.trac/specs/

This directory is the SINGLE SOURCE OF TRUTH for system documentation.

Never duplicate spec data outside this directory.

---

# OUTPUT FILES (MANDATORY)

.trac/specs/
  architecture.json
  frontend.json
  backend.json
  database.json
  apis.json
  infra.json
  toolchain.json
  dependencies.json
  sandboxes.json
  changelog.json

Create missing files.
Update only impacted files.
All outputs must be strict JSON.
No markdown.
No comments.
No explanations.

# DEEP ANALYSIS REQUIREMENTS

You must detect, extract, normalize, and document the following:
