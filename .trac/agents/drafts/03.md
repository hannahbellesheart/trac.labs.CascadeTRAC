.trac/specs/

# DRIFT DETECTION SYSTEM

On full scan:

1. Compute repository structural hash from:
   - package files
   - migrations
   - workflows
   - infra configs
   - env files

2. Compare to .trac/_meta.json.repositoryHash

If mismatch:
- Calculate driftScore (0–100)
- Identify impacted layers
- Update affected spec files only
- Append changelog entry

- Layer impact
- Dependency ripple
- API contract impact
- Security surface change

Store:

Write to governance.json.
